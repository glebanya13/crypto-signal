# Crypto Signal Bot - MVP

Асинхронный Telegram-бот для аналитики **Binance Spot**. На этом этапе доступны публичные реальные котировки и свечи, уровни по swing-экстремумам, приближенный объемный профиль, свечные объемы/RVOL/VWAP, текстовый отчет и PNG-график. Бот не имеет торговых ключей и не совершает сделки.

## Запуск локально

Нужен Python 3.12+ и Telegram bot token.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
# задайте TELEGRAM_BOT_TOKEN в .env
python -m app
```

## Telegram / BotFather

В Telegram откройте `@BotFather`, выполните `/newbot`, задайте имя и username, скопируйте токен в `TELEGRAM_BOT_TOKEN`. Токен секретен: не коммитьте `.env`.

Бот принимает `SOL`, `BTC`, `ETH`, `SOL/USDT`; команды `/analyze SOL [4h]`, `/levels BTC [1d]`, `/volume ETH [15m]` и `/chart SOL [1h]`. Поддерживаются 5m, 15m, 1h, 4h, 1d, 1w. `/whales SOL` - крупнейшие сделки ленты, `/orderbook BTC` - стакан Binance Spot.

### Как пользоваться (inline-кнопки)

`/start` -> выбрать монету -> меню экранов. Все экраны переключаются в одном сообщении (оно редактируется), таймфрейм меняется кнопками, график приходит картинкой. Кнопка «🔄 Обновить» перезапускает текущий экран и добавляет блок «Что нового»: изменение цены, смену направления Long/Short, структуры рынка, знака Delta, новые крупные сделки и всплески (если тот же экран открывали менее 2 часов назад). Один пользователь обрабатывается по одному запросу, между запросами пауза 1.5 с; свечи и лента сделок кэшируются на 15-20 с.

### Экраны

- `/signal SOL` - Long/Short: сила сигнала 0-100 (взвешенная сумма факторов: тренд, VWAP, Delta ленты, SMC-структура, Premium/Discount, осцилляторы без EMA, расположение у уровней), зона входа **на откате** (поддержка, Order Block или FVG), стоп за зоной, цели по уровням, риск/доходность. Сделки с R/R ниже 1.5 не предлагаются (на истории они убыточны).
- `/smc SOL` - Smart Money: BOS/CHoCH, Order Blocks, FVG, пулы ликвидности и сносы, Premium/Discount.
- `/ta SOL` - EMA 20/50/200, RSI, MACD, Bollinger, ATR, дивергенции, тренд на 15m/1h/4h/1d.
- `/levels SOL` - зоны поддержки/сопротивления (касания, давность последнего теста, объем), HVN/LVN, Pivot Points, недавние пробои и ретесты.
- `/volume`, `/whales`, `/orderbook`, `/chart`, `/analyze` - объемы и поток сделок, крупнейшие сделки за 1 час, стакан, график (закрытые свечи, зоны, VWAP, Value Area, OB/FVG, метки крупных сделок), общий отчет.
- `/backtest SOL [tf]` - прогон тех же правил на последних ~4000 свечах без подсмотра в будущее: лимитный вход, стоп приоритетнее цели, комиссия 0.05R, одна позиция за раз.

**Честный результат бэктеста.** Пока правила не показывают устойчивого преимущества: на 6 монетах (1h, ~160 дней) средний результат около нуля (от -0.1R до 0.0R на сделку), сила сигнала не связана с результатом. Поэтому сигнал нужно рассматривать как структурированное описание рынка с зоной входа и стопом, а не как прибыльную стратегию. Бэктест не учитывает поток сделок (исторической ленты нет).

Все расчеты считаются только по закрытым свечам. Правила SMC механические и описывают структуру цены, а не действия конкретных участников.

## Конфигурация

- `TELEGRAM_BOT_TOKEN` - обязательный токен.
- `DEFAULT_EXCHANGE` - Binance; MVP использует только Binance Spot.
- `DEFAULT_QUOTE` - USDT.
- `DEFAULT_TIMEFRAME` - 1h (командой можно выбрать таймфрейм).
- `LOG_LEVEL` - INFO по умолчанию.

## Данные и ограничения

Источник - публичный Binance Spot API через CCXT, без API-ключа. В сообщении указывается время получения. Пара проверяется по рынкам Spot; ошибки API не маскируются как нули. Уровни формируются кластеризацией локальных swing high/low; сила - прозрачная эвристика по числу касаний, не вероятность пробоя. Volume Profile распределяет объем свечи по typical price, то есть является приближением.

Важная оговорка: Buy/Sell Volume и CVD считаются по ленте `aggTrades` (последние ~50 000 сделок через публичный REST; для BTC это ~1 час, для менее ликвидных монет - несколько часов; окно 1ч показывается только если лента его покрывает, иначе `н/д`). Это сторона агрессора, а не приток или отток денег. Крупные сделки - динамический порог (p99.9 и ≥30× медианной сделки), серии - ≥5 сделок уровня p99 одной стороны подряд, всплески - робастный z-score (медиана/MAD) оборота за минуту. Стакан синхронизируется по REST snapshot + WebSocket (правила Binance Spot). Лента кэшируется на 20 секунд. Данные берутся с публичного зеркала `data-api.binance.vision` (работает там, где `api.binance.com` отвечает 451). On-chain, деривативы (OI, funding, ликвидации), уведомления, PostgreSQL и Redis пока не реализованы. Профиль объема (POC/VAH/VAL) приближенный - по свечам, а не по сделкам.
